# Local reference runs

JSON files in this folder are generated by the benchmark scripts, not hand-entered timings.
They include every sample, arguments, package versions, hardware (when available), thread settings,
and a completed-work timing contract. See [the performance guide](../../docs/performance.md).

Do not use these results to claim universal superiority, CUDA performance, or frontier-model scale.
Run on your deployment hardware and actual batch/context/model sizes. Avoid concurrent benchmarks.
